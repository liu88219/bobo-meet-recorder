# BoboMeet 🎙️ Quokka & BOBO 會議輕量錄音室

韓系簡約奶油風格的一鍵會議純音訊錄音小工具（支援 PWA 加入主畫面與跨瀏覽器加密同步）：

- **💻 線上會議模式（分頁音訊 ＋ 麥克風）**：非會議主持人、戴耳機開會也能同時錄下會議分頁音訊與自己的麥克風（錄音中還可隨時單獨靜音麥克風）。
- **🏢 實體會議室／隨身純麥克風模式**：支援桌機與手機瀏覽器，錄音期間自動啟動螢幕防休眠（Wake Lock）。
- **🪶 超輕量純音訊（1 小時僅約 14 MB）**：只編碼高清晰語音軌、不錄肥大螢幕影像，比全螢幕錄影小 30 倍。
- **🛟 每 5 秒防當機自動寫入 IndexedDB**：即使瀏覽器意外關閉或重開，下次打開也能一鍵救援還原音檔。
- **📌 會議重點時間戳 ＆ 一鍵複製轉逐字稿指令**：開會途中隨手標記 `[MM:SS]` 重點，會後一鍵下載音檔、開啟雲端資料夾並複製轉逐字稿指令。
